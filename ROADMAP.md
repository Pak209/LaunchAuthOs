# Launch Auth — Roadmap

## Now

- Supplier due diligence and evidence matrix.
- Directory automation investigation.
- Unit economics with assumptions separated from verified costs.
- MVP architecture and data model.

## Next

- Implement URL intake, source-linked Brand Profile, readiness assessment, and claim approval.
- Add one provider adapter in a sandbox/test mode.
- Add one assisted directory adapter.
- Generate an evidence-backed report.

## Later

- More providers and directories.
- Authority Graph and recurring opportunity engine.
- Monitoring subscriptions and AI visibility observations.

## Gate

Do not commit to production fulfillment architecture until the supplier matrix, economics, directory matrix, and thin-slice design are sufficiently validated.
